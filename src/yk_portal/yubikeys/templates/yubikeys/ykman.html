How to program a YubiKey with ykman

On a trusted computer with the YubiKey Manager (ykman), program slot 2, which types an OTP on a long touch:

ykman otp yubico 2 --serial-public-id --generate-private-id --generate-key

It shows a public ID, a private ID and a secret key: enter them below. Slot 1's factory setting can't be restored once replaced, so use slot 2 unless you're sure. Don't add --upload: it sends the key to Yubico.
